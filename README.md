# Seha Referrals App for Case Coordinators

**By Dr.Fahad Aldawood**

Windows application for opening an authorized Seha School Screening referral after choosing a PHC and entering a student ID. Includes Arabic/English controls, full PHC names, and application updates.

## Download and start

1. Open [Releases](https://github.com/DrFnan194/Seha-Referrals-App-For-Case-Coordinators/releases/latest).
2. Download **SehaReferral-Windows-x64.zip** and extract all files into a permanent user-writable folder.
3. Run **SehaReferralApp.exe**.
4. Sign in through Seha/Nafath, select your available account and PHC, then open referrals.

## Updates

From version 1.1.0, the app checks GitHub Releases for newer stable versions. Finish any clinical work, return to the referral list, then choose **Download and restart / تنزيل التحديث وإعادة التشغيل** when offered. Earlier builds require one manual installation of version 1.1.0 to receive future updates.

The updater verifies the download checksum, backs up replaced application files, and preserves the separate Seha browser profile. Members do not need a GitHub account for public downloads or update checks.

## الاستخدام بالعربية

نزّل الملف المضغوط من صفحة الإصدارات، واستخرج جميع ملفاته في مجلد ثابت، ثم شغّل **SehaReferralApp.exe**. سجّل الدخول عبر نفاذ، واختر المركز الصحي المتاح لحسابك، ثم افتح الإحالات وأدخل هوية الطالب. يمكنك اختيار **العربية** من قائمة اللغة أعلى التطبيق.

عند توفر تحديث، أكمل أي تعديلات وارجع إلى قائمة الإحالات، ثم اختر **تنزيل التحديث وإعادة التشغيل**.

Each member uses their own normal Seha permissions. Student identity and screening record must match before a report is shown as verified. The application does not save clinical reports automatically. This independent helper does not replace Seha as the authoritative system.

This repository hosts application releases. Do not upload browser profiles, login tokens, patient records, clinical screenshots, or referral datasets.
